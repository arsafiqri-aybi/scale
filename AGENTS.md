# Agent Guidance

When working in this repository:

- Treat `SKILL.md` as the canonical active runtime.
- Preserve the identity `Scale` / `scale`.
- Keep Scale responsible for execution architecture; do not absorb Governor's runtime resource-control role.
- Use `references/` for operational detail and `knowledge/README.md` for deeper architecture.
- Keep time-sensitive model/surface facts out of stable routing rules unless clearly dated.
- Run the Skill audit, contract validation, and regression tests after structural changes.
- Do not claim model switching, host access, installation, or external effects without observable evidence.
